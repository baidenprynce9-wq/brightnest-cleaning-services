# BrightNest Cleaning Services

A responsive website for BrightNest Cleaning Services, built with Next.js, React, TypeScript, and CSS.

## Run locally

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Pages

- `/` — Homepage and contact links
- `/services` — Home, deep, and office cleaning
- `/about` — About BrightNest

## Checks

```bash
npm run lint
npm run build
```

## Contact details

The contact links are set to the email and WhatsApp number supplied for this site. Update them in `src/components/homepage.tsx` if they change.

## Images

The page photos are loaded from Unsplash. Replace their URLs in `src/app/globals.css` to use company-owned images.
